# 취향 여권 (TastePass)

> 취향을 설명하지 마세요. 당신의 방이 이미 말하고 있습니다. 그리고 그 취향의 주인은 당신입니다.

GEEKs Ideathon 2026 출품작 프로토타입입니다. 내 방과 물건, 저장한 이미지에서 취향을 모아 **취향 여권**을 만들고, 그 여권 하나로 어느 제휴 쇼핑몰에서든 나에게 맞춘 상품을 보여주는 **추적 없는 초개인화** 플랫폼입니다.

## 바로 보기

설치 없이 `prototype/tastepass-prototype.html` 파일을 브라우저로 열면 됩니다.

## 주요 화면

| 화면 | 내용 |
|---|---|
| 서비스 소개 | 서비스 개요, 취향을 모으는 4단계, 가맹점 예시, 개인정보 원칙 |
| 여권 만들기 | 방 스타일 스와이프 → 주문내역·저장 이미지·내 방 사진 가져오기(샘플) → 여권 완성 |
| 3D 스튜디오 · 방 꾸미기 | 방 치수 입력, 가진 물건 배치, 드래그로 이동, 15°/90° 회전, 겹침·벗어남 표시, 취향+남은 공간 기준 추천 놓아보기 |
| 3D 스튜디오 · 체형 | 키·어깨·가슴·허리·엉덩이·다리 비율로 마네킹 생성, 옷 입혀보기, 체형 기반 추천 사이즈와 S~XL 핏 비교 |
| 가맹점 | 가상 쇼핑몰 2곳(인테리어·패션). 동의 후 ‘취향 여권으로 입장’하면 상품 순서가 바뀜, 재정렬 API 요청·응답 보기 |
| 내 여권 | 취향 카드 직접 수정, ‘내 취향 아님’ 신호 제외, 입국 도장, 동의 철회 |

## 실행 (개발용)

```bash
npm install
npm run dev
```

## 구조

```
src/
  App.jsx      화면 흐름과 전체 상태
  Site.jsx     홈, 여권 만들기, 가맹점, 내 여권 페이지
  Studio.jsx   3D 스튜디오 (방 꾸미기 / 체형·입어보기)
  gl.js        직접 만든 WebGL 렌더러 (조명, 그림자, 선택 외곽선, 카메라, 클릭 판정)
  models.js    가구, 마네킹, 옷 3D 모델 생성
  engine.js    취향 계산, 방 배치·겹침 판정, 사이즈 추천
  data.js      샘플 데이터 (가상 상품, 가상 가게)
  style.css    디자인
prototype/
  tastepass-prototype.html   빌드된 단일 파일
```

## 핵심 설계

- **취향 엔진**: 색감·소재·무드 공통 축으로 취향을 저장해 인테리어 취향을 패션에도 씀. 구매 ×3, 저장·사진 ×2, 좋아요 ×1 가중치.
- **재정렬 API**: 가게는 상품 목록만 보내고, 여권은 순서와 점수만 돌려줌. 취향 원본과 체형 치수는 밖으로 나가지 않음.
- **3D**: 외부 라이브러리 없이 WebGL로 직접 구현. 인터넷 없이도 동작.

모든 상품, 가게 이름, 데이터는 시연용 가상 데이터입니다.
